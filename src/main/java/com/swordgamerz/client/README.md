# OWN CLIENT

### Your Game. Your Rules.

OWN CLIENT is a Minecraft Java Edition Fabric client project.

## Features
- FPS HUD
- Coordinates HUD
- Keystrokes HUD
- Armor HUD
- Ping HUD
- Crosshair customization
- Zoom
- Fullbright
- Custom configuration

## Project Details
- Minecraft: 26.2
- Fabric Loader: 0.19.3
- Java: 25

## Build
Run:

./gradlew build

The generated JAR will be available in:

build/libs/
